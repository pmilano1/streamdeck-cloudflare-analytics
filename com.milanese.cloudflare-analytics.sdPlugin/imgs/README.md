# Plugin Images

This directory should contain the following images:

## Required Images

1. **plugin-icon.png** (72x72 or 144x144)
   - Main plugin icon shown in Stream Deck marketplace

2. **category-icon.png** (28x28 or 56x56)
   - Category icon for the plugin

3. **action-icon.png** (72x72 or 144x144)
   - Icon for the Cloudflare Stats action

4. **key.png** (72x72 or 144x144)
   - Default state icon for the button

## Image Guidelines

- Use PNG format with transparency
- Provide @2x versions for retina displays
- Keep designs simple and recognizable at small sizes
- Use Cloudflare orange (#F38020) for branding consistency

## Creating Icons

You can create simple icons using:
- Figma, Sketch, or Adobe Illustrator
- Online tools like Canva
- The Cloudflare logo (ensure proper licensing)

For now, you can use simple colored squares or the Cloudflare logo as placeholders.
